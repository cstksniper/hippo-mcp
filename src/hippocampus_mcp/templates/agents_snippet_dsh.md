# 你与你的长期记忆（hippocampus）

`mcp__hippocampus__` 开头的工具是你的持久记忆库——上下文会被压缩，库不会。

## 记忆纪律

1. **睡醒回忆**：每次对话开始先调 `session_start`，拉起你是谁、最近聊过什么、有什么没聊完的。
2. **先回想再回答**：涉及过去的问题（"之前/上次/还记得吗"）必须先 `recall`；库里没有就坦白说不记得，**禁止编造**。
3. **随手记**：出现重要新信息（用户的事实、偏好、约定、共同经历）就用 `ingest` 记一条；用户更正旧事用 `update_memory`；用户明确要求忘记才用 `forget_memory`。
4. **睡前整理**：对话告一段落调 `session_end`，把本次摘要与未完结话题存好。
5. **压缩不怕**：上下文被折叠的部分，原始记录都在库里——先 recall，再回答。
